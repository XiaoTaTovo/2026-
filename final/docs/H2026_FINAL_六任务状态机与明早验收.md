# H2026 Final 六任务状态机与明早验收

## 证据分类

- **题面事实**：官方 PDF 第 2 页要求 1-6；第 3 页给出 1.5 m 直线、R0.5 m
  半圆、A 横线、唯一测试点、红外循迹和启动计时要求。
- **计算**：正式一圈长度
  `2*1500 + 2*pi*500 = 6141.59 mm`。
- **源码事实**：路线唯一由 `app/h2026_task.c` 生成；KEY1/2/3 经
  `firmware.c` 的三个 `Button` 对象去抖；OLED 每次只同步发送一页，不等待整屏。
- **经验初值**：速度、PI/P-D、搜索距离和 150 mm 偏置均未在 final 镜像上实测。
- **UNKNOWN**：RED 型号/VCC/IR、真实球控同步接口、图传完成信号、最终机械尺寸与
  编码器标定。

## 状态机

```text
                         KEY3（仅停止）
        +--------------------------------------------------+
        v                                                  |
      READY --KEY1--> RUN --路线完成或外部 DONE--> DONE --+
        |              |
        |              +--KEY1/STOP--> FAULT（急停锁存）
        |              +--KEY2/KEY3--> 拒绝，任务不变
        +--KEY2--> WHITE 16帧 -> BLACK 16帧 -> OK/FAIL
```

`FAULT` 不通过切任务清除；必须排除原因后复位。T2/T4/T5/T6 若没有 `SCAN OK`，
KEY1 被拒绝。T1/T3 不使用巡线，可在未标定时进入外部等待，但全局硬件故障仍会拒绝
启动。

## 任务表

| 任务 | 小车动作 | 完成证据 | 外部依赖 |
| --- | --- | --- | --- |
| T1 | 电机持续零输出 | 台架 `DONE` 后状态为 DONE | 图传真实录像/回放不在本工程 |
| T2 | AB、BC 右半圆、CD、DA 右半圆 | A 横线确认 + 传感器到唯一点偏置 | 无滚球依赖 |
| T3 | 电机持续零输出 | 台架 `DONE` 后状态为 DONE | 球 O->+5 cm->-5 cm 属于球控端 |
| T4 | AB 直线 1500 mm | 唯一测试点严格通过 1500 mm 后同拍停车并 DONE | 球保持 O、START_SYNC 未接 |
| T5 | 与 T2 相同完整圈 | A 横线 + 偏置后 DONE | 球保持 O、START_SYNC 未接 |
| T6 | 与 T5 相同完整圈 | A 横线 + 偏置后 DONE | 任意位置锁存和保持未接 |

T2/T5/T6 的四个运动段只引用 2026 题面常数，不读取或复用 2024 H 路线表。

## 量化验收

### 无电机/架空轮

1. 冷启动首行是 `RED T1 READY`；连续按 KEY3 六次必须依次显示 T2..T6、T1，
   每次只跳一项。
2. T1 按 KEY1 后显示 RUN、RPM 均为 0；运行中 KEY3 不换任务且 `REJ` 加一。
3. T1/T3 蓝牙发送 `DONE` 后 100 ms 内显示 DONE；T2/T4/T5/T6 发送 `DONE`
   必须返回 `EXTERNAL_TASK_NOT_RUNNING`。
4. 任一 RUN 状态再次按 KEY1，TB6612 STBY/PWM/方向输出应立即进入停车逻辑并显示
   FAULT；复位前 KEY1 不得重启。
5. 白面按 KEY2，约 160 ms 后显示 `SCAN BLACK`；换全黑面再按 KEY2，约 160 ms
   后必须为 OK 或带通道号的 FAIL，过程中串口和任务按键仍被服务。
6. 合成/台架输入下，2 个连续黑通道不得触发 A 横线；3 个连续通道且活跃均值
   `>=600/1000` 连续 2 帧必须触发，8 路均匀灰背景不得触发。

### 落地小车侧

1. 先只选 T4，低速验证 A->B 1500 mm；10 次都不完全脱线，记录编码器距离、时间、
   最大线误差和电池电压。
2. T2 完整圈先以当前 350/300 mm/s 跑通；A 横线触发后检查唯一测试点偏差，单变量
   修正 `finish_sensor_to_test_point_mm`。
3. T5/T6 在没有滚球载荷时只能验路线一致性；有滚球后才按 24-26 s 预算调加减速。
4. 强光、阴影、低电、冷启动、短时丢线分别至少 10 次；任何场景完全脱线、误识别 A
   横线或急停失败均判失败。

## STOP / FIX / IMPROVE

- **STOP**：未架空验证轮向、编码器符号、KEY1/STOP 和左右编码器断线停车前，禁止
  直接落地跑整圈或提高 PWM 上限。
- **STOP**：RED VCC、输出最大电压和 IR 语义没有型号/数据手册证据，禁止把 IR 继续
  试接 3.3 V/5 V，也不能据此改 GPIO 驱动。
- **FIX**：T2 当前理想下限 19.04 s，尚无 16-17 s 余量；先跑稳，再根据编码器实测
  提升速度并重新验收停车。
- **FIX**：T3-T6 缺真实 START_SYNC/球控健康/失效接口；接入前不得称为整机状态机。
- **FIX**：150 mm 偏置、轮径、CPR、左右轮有效轮径和 R500 等效轮距必须实测。
- **IMPROVE**：滚球端接入后增加带序号、时间戳、有效位和超时的单向任务帧；不让球控
  故障覆盖 KEY1/TB6612 本地急停。
- **IMPROVE**：OLED 是单页 3.2~3.4 ms 的有界同步发送，不是真正 DMA 非阻塞；明早
  先量 20 ms 控制周期抖动，有明显超期再改 DMA/IRQ。
- **IMPROVE**：稳定后再实现按任务区分的 jerk/加速度曲线，并保留当前低速参数作为
  可回退配置。
