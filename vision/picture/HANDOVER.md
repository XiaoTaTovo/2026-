## 4. 关于 SSH：能不能插到你电脑上用？—— 能，而且很简单

**先说结论：SSH 是客户端工具，不存在"我这台电脑专属"的问题。你的 Windows 10/11 自带 OpenSSH 客户端，不用装 PuTTY、不用我的密钥，直接用密码登录就行。** 需要满足的只有两件：树莓派 sshd 开着（已开），以及网络能通。

### 4.1 首选：主机名直连（已实测可用）

```powershell
ssh pi@xiaotpi.local
```

Win11 内置 mDNS 解析，这条实测直接能通，不用配任何 IP —— 同一个热点下、或网线直连时都适用。看 UI 同理：`http://xiaotpi.local:8000`。

### 4.2 兜底：网线直连固定 IP

万一换了机器 mDNS 不灵、或环境变了，还有一条死路子。树莓派那边已配好（`scripts/net-eth-direct.sh`）：eth0 用 `ipv4.method auto` **同时**挂一个附加静态地址 `192.168.50.1/24`。这样插路由器能拿 DHCP 上网装包，直连笔记本也永远有 `192.168.50.1` 这个固定入口，不用猜 IP。

**笔记本上做一次：**

1. 网线一头插树莓派，一头插笔记本网口。
2. Windows：设置 → 网络和 Internet → 以太网 → IP 分配「编辑」→ 手动 → 打开 IPv4：
   - IP 地址 `192.168.50.2`
   - 子网掩码 `255.255.255.0`
   - **网关和 DNS 留空**（留空才不会抢走你 WiFi 的上网）
3. 保存后开 PowerShell：

```powershell
ping 192.168.50.1
ssh pi@192.168.50.1
```

第一次会问 `Are you sure you want to continue connecting?` → 输入 `yes`，然后输密码。搞定。

> 这样配的好处：你笔记本的 WiFi 还能照常上网（网线只走 192.168.50.x 这个小网段），一边查资料一边 SSH。

### 4.3 想免密登录（可选）

在你笔记本上：

```powershell
ssh-keygen -t ed25519          # 一路回车
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh pi@192.168.50.1 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

**不要把我电脑上的私钥拷给你**——没必要，生成新的更快也更干净。

### 4.4 如果现场需要临时给树莓派上网装东西

Windows「网络共享(ICS)」把 WiFi 共享给以太网。注意 ICS 会强制把你的网口设成 `192.168.137.1`，**会覆盖上面的 192.168.50.2 设置**，树莓派会变成 `192.168.137.x`，SSH 地址得重新找（`arp -a` 里看）。所以：**只在真要装包时开 ICS，装完立刻关掉、把静态 IP 改回来。** 正常比赛全程都不需要开。

### 4.5 最重要的一句

**SSH 只是后手。** 触摸屏 UI 已经把现场要用的功能全做进去了（换信道、改相机参数、重启相机/服务、清理存储、安全关机）。**你比赛全程理论上不需要碰一次命令行。** 键盘鼠标带着，是给触摸屏失灵时用的。

## 5. WiFi 怎么连：三种链路，优先级从上到下

| 方案 | 谁发热点 | 什么时候用 | 怎么切 |
|---|---|---|---|
| **A（默认）** | 树莓派 wlan0 发 `BALLCAM_H` | 常态。ESP32-CAM 作为客户端连它 | 开机自动，不用管 |
| **B（备用）** | ESP32-CAM 自己开 SoftAP | 树莓派 AP 起不来时救急 | 相机长按 BOOT 切模式 + UI 设置页点「模式 B」 |
| **C（模块到货后）** | 那个还没到的 WiFi 模块/随身路由 | 到货后作为正式方案，更稳且树莓派能恢复上网 | 树莓派改连它，或直接网线插它 LAN 口 |

**不要用第二块 ESP32 当热点转发图传**——它的 SoftAP 吞吐会成瓶颈，画面必卡。那块留着当备用发送模块（摔了一个还有一个）。

### 现场第一件事：扫信道

赛场几十支队伍加观众手机，2.4G 会被打爆，**这是本项最大失分风险**。到场先在 UI 设置页点 **[🔍 扫描并推荐空闲信道]**，选 1/6/11 里最空的那个，一键换台。中途如果画面开始卡，再扫一次再换。

## 6. 开机 5 分钟自检（每天到场、每次上台前都跑一遍）

1. **只给树莓派插电**，不碰键鼠 → 60 秒内应自动出现全屏 UI，顶栏显示 AP 已启动。
2. **给小车/相机上电** → 15 秒内顶栏相机灯变🟢绿，画面出来。
   （相机会比 AP 先启动、先连不上，固件里是无限重连，等就行，别急着断电重上。）
3. 画面里**摆杆两端刻度都在框内**，钢球清晰，没有大反光斑。不对就调支架高度/角度。
4. 选测试项 `T4` → 点**开始录制** → 数 5 秒 → **停止** → 底部绿条出现 → 点**立即回放** → 能播、能逐帧、能 0.25x 慢放。
5. 顶栏剩余空间 > 5GB，时间显示正确（时间不对去设置页校时）。

**五步全过 = 图传这 6 分稳了。** 任一步不过，翻 §8 排障。

## 7. 评委面前的标准操作流程（背下来）

**录：** 选测试项 → 点 REC（红色满屏填充，很明显，评委看得到在录）→ 小车跑 → 点停止。

**放：** 评委说"回放第 4 项那次" → 点底部 [回放] → 左侧点 `T4` 筛选 → 最上面就是最新那条 → 点 ▶。
需要看最大偏差那一帧：先 `0.25x` 慢放接近，再按 `|▶` **逐帧步进**定格，配合刻度线叠加读位置。

**加分动作：**
- 开 `⊹ 刻度线` 叠加，画面上直接标出 -5/0/+5cm，评委看要求 3/4/5/6 时能一眼判位。
- 录制中在关键瞬间（过 B 点、球到 +5cm）点 `⚑ 标记`，回放时进度条上有三角可一键跳。
- 想让评委看清楚就点 `⛶ 全屏`。

**收：** 每天结束前用 U 盘导出当天录像 + json，给我写报告用（"测试数据完整性"占 4 分）。

**关：** 设置页 **长按 [⏻ 安全关机] 1.5 秒**。**永远不要直接拔电**——会烧卡、损坏录像。

## 8. 排障速查

| 现象 | 先查 | 怎么办 |
|---|---|---|
| **屏幕插着但不亮** | 有没有本地图形会话 | 跑 `./scripts/screen-fix.sh`（只诊断不改文件），照它的结论办。最常见是「一直用 SSH/xrdp，本机 seat0 上压根没起桌面」→ `raspi-config` 开 Desktop Autologin 后重启 |
| 开机没进 UI，停在桌面 | 服务/kiosk 没起 | `systemctl status ballcam-api`；或设置页 [重启服务]；手动起一次 `./scripts/kiosk-run.sh` |
| AP 没启动 | 国家码/rfkill | `nmcli con up ap-ballcam`；`rfkill unblock all`；`sudo raspi-config` 确认 WLAN Country=CN |
| 相机连不上 | 供电 > WiFi | ①测相机 5V 有没有跌落（**最常见原因**，WiFi 发射尖峰导致 brownout 重启）②确认 SSID/密码 ③换信道 ④换方案 B |
| 画面卡/延迟大 | 频段拥塞 | 扫信道换台；分辨率降到 VGA；画质数值调大（15）；把树莓派挪近赛道边（仍在线外） |
| 画面糊/看不清刻度 | 曝光和补光 | 曝光切「固定」并调；加侧向漫射补光；提高分辨率到 SVGA；确认镜头对焦（OV2640 镜头可手动旋转对焦） |
| 球上有白亮斑读不出位置 | 补光角度 | 别正打，改侧向漫射；关掉板载闪光灯 |
| 录像播不了 | 转码/格式 | 播 `rec/mp4/` 里的；`rec/raw/` 的 mkv 是保底原始档，用 VLC 或让我这边处理 |
| 录像中途断了 | 相机掉线 | 正常，会自动生成 part2，UI 回放会连续播完。列表上标 `⚠ 2分片` |
| 触摸不灵 | 驱动/校准 | 接 USB 鼠标；或网线连笔记本用浏览器开 `http://xiaotpi.local:8000` 操作同一套 UI |
| 开了 ffplay/VLC 直连相机后画面没了 | 抢流 | ESP32-CAM 只允许**一路** `/stream` 客户端。要单独用 ffplay 验证图传，先 `sudo systemctl stop ballcam-api`，验完再 start |
| 时间不对（录像时间戳乱） | 离线无 NTP | 设置页 [校时]；长期建议加个 DS3231 RTC（¥10） |
| 树莓派彻底起不来 | SD 卡 | **换备份卡**，5 分钟恢复。这是带备份卡的唯一理由 |
