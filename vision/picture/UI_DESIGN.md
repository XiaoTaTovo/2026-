# 触摸屏 UI 设计（ballcam 接收端）

设计前提：**7 英寸 1024×600 电容触摸，横屏，无键盘无鼠标，戴手套/手指粗操作，赛场光线亮、有人围观。**

## 0. 设计原则

1. **最小点击数**：最高频动作是「开始录 → 停 → 立刻回放」。这三步必须都在**首屏一次点击**内完成，不翻页不弹窗。
2. **手指尺寸**：主操作按钮 ≥ 88×88px，次级 ≥ 64px，间距 ≥ 12px。绝不用悬停态（触摸没有 hover）。
3. **深色底 + 高对比**：`#0E1116` 底，主色青 `#22D3EE`，录制红 `#EF4444`，成功绿 `#22C55E`。赛场顶灯反光下浅色底会看不清。
4. **状态永远可见**：相机连通、录制中、剩余空间、fps 常驻顶栏，评委和自己一眼看到系统活着。
5. **不可逆动作要二次确认**：删除、关机、格式化 → 长按 1.5s 环形进度确认，不弹小对话框（小对话框在触摸屏上难点）。
6. **不依赖网络字体/CDN**：全离线，系统字体 + 内联 SVG 图标。

## 1. 全局框架

```
┌───────────────────────────────────────────────────────────────┐ 1024
│ ● CAM 10.42.0.23  14.7fps │ ●REC 00:12.4 │ 26.3GB │ 14:25 │⚙│ 48px
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                       内容区（三页切换）                       │ 480px
│                                                               │
├───────────────────────────────────────────────────────────────┤
│      [ 实时 LIVE ]      [ 回放 PLAY ]      [ 设置 SET ]        │ 72px
└───────────────────────────────────────────────────────────────┘ 600
```

顶栏状态灯语义（一眼看健康度）：

| 灯 | 含义 |
|---|---|
| 🟢 绿常亮 | 相机在线，fps ≥ 10 |
| 🟡 黄 | 在线但 fps < 10 或延迟高 |
| 🔴 红闪 | 相机离线，后端正在重连（旁边显示"重连中 3s"） |
| ⚫ 灰 | 后端自己挂了（前端轮询超时，提示"点此重启服务"） |

底部三页签：常驻，图标+中文，选中项青色顶边+加粗。**录制中切页不中断录制**（录制在后端 ffmpeg，与前端解耦，这点很关键——评委让你翻个页不能把录像弄断）。

```

```

### 画面区（左，约 660px 宽）

- `<img src="http://10.42.0.23:81/stream">`，浏览器直连相机，**不经后端转发**——省一次转码/搬运，延迟最低，树莓派 CPU 留给 ffmpeg。
- 相机断线时 `<img>` 会停在最后一帧（容易误判"还活着"）。所以后端心跳一旦判离线，**画面上盖半透明遮罩 + "相机离线，重连中…"**，绝不让评委看到假画面。
- **刻度线叠加**（`⊹` 开关）：在画面上叠一层半透明 SVG，画 -10/-5/0/+5/+10cm 的竖线和 0 点十字。位置来自设置页的两点标定（点画面上摆杆 -10 和 +10 两端，线性映射）。用途：评委问"球现在在哪"，直接指着看，比数凹槽刻度快得多，也是要求 3/4/5/6 目视复核的利器。
- **全屏** `⛶`：画面铺满 1024×600，只留一个悬浮返回。评委围观时用这个。
- **截图** `◉`：存 `shots/`，写报告插图直接用。

### 测试项选择（右上，2×3 网格）

对应题目要求：`T1 图传` / `T3 静止±5cm` / `T4 A→B` / `T5 整圈30s` / `T6 任意位置` / `自由`。
**必须先选测试项再录**，未选时 REC 按钮灰掉并提示"先选测试项"。这是为了让文件名天生带语义 —— 后面回放检索、写报告全靠它。选中项青色填充。

### 录制按钮（右下，96px 高，全宽）

三态：

| 状态 | 外观 | 点击行为 |
|---|---|---|
| 待录 | 深底 + 红圆点 + "开始录制" | 立即启动 ffmpeg |
| 录制中 | **红底满填充** + "■ 停止 00:12.4" + 呼吸动画 | 停止并落盘 |
| 启动中 | 灰 + 转圈 | 禁用（防连点产生两个 ffmpeg） |

录制停止后，**画面区下方浮出一条 4 秒后自动消失的绿色条**：`✔ T4_20260731_142513.mp4  12.4s / 183帧  [立即回放]`。点「立即回放」直接跳回放页并播这条 —— 这是"评委说'放一下'"的最短路径，一共 3 次点击完成录+停+放。

### 标记按钮 `⚑`

录制中点一下，把当前相对时间戳写进 sidecar 的 `marks[]`。用途：小车通过 B 点/球到达 +5cm 的瞬间打点，回放时进度条上出现小三角，可一键跳过去。写报告分析和现场自证都好用。

```
│  T4 14:12:47 │                                                │

│ ─────────────│                                                │

│              │                                                │
│              │   [⬇ 导出U盘]  [♻ 删除(长按)]                  │
├──────────────┴────────────────────────────────────────────────┤
│      [ 实时 ]         [ ●回放 ]           [ 设置 ]             │
└───────────────────────────────────────────────────────────────┘
```

### 左侧列表（280px）

- 顶部按测试项筛选（全部/T1/T3/T4/T5/T6/自由），一点即筛。评委说"看第 5 项的录像" → 点 T5，列表只剩 T5，最新在最上。
- 每条卡片：**测试项徽章 + 时刻 + 时长 + 帧数 + 标记数**。卡片高 88px，好点。
- `⚠ 2分片` 标签表示中途断线重连过，播放时自动连续播完所有分片（对使用者透明）。
- 竖向滑动惯性滚动，不做分页。

### 播放器（右侧）

- `<video src="/rec/mp4/xxx.mp4">`，原生解码，硬件加速，seek 快。
- **叠加层**：左上「帧 62/183」+「00:04.20」，可叠刻度线（和实时页同一套标定）—— 定格读球位就靠它。
- **逐帧 `◀| |▶`**：`video.pause(); video.currentTime ±= 1/fps`。**这是"按要求回放"的核心能力** —— 评委要看球最大偏差的那一帧，逐帧步进能精确停住。因为录制时 `-g 15`，seek 精度足够。
- `◀◀ ▶▶`：±3s 快退快进。
- **倍速**：`0.25x` 慢放看球滚动细节（30s 整圈的小抖动，慢放才看得清）；`2x` 快速掠过。
- 进度条上的 `⚑` 小三角 = 标记点，点它直接跳。
- **导出 U 盘**：插 U 盘 → 一键把选中记录（mp4 + json，可选 raw mkv）拷过去。用途：给我这边写报告、当天备份，不用 SSH。
- **删除**：长按 1.5s，按钮上走一圈红色环形进度，松手取消。防误删。

## 4. 页面三：设置 SET

三栏卡片布局，全都是大按钮/大滑块，不需要键盘输入（IP 之类用数字键盘 pad 组件）。

```
┌───────────────────────────────────────────────────────────────┐
│ 网络与链路              │ 相机参数         │ 系统            │
│ ───────────────────────│─────────────────│─────────────────│
│ 模式 [A 派做AP*][B 相机AP]│ 分辨率           │ 存储 26.3/29.7GB │
│                        │ [VGA][SVGA*][XGA]│ ████████░░ 88%   │
│ SSID  BALLCAM_H        │                  │                  │
│ 信道  [1][6*][11]      │ 画质 ──●──── 12  │ [♻ 清理7天前]    │
│ [🔍 扫描并推荐空闲信道]  │ 亮度 ───●─── 0   │                  │
│                        │ 曝光 [自动][固定*]│ [↻ 重启服务]     │
│ 相机 10.42.0.23 ●在线   │      ──●──── 300 │ [↺ 重启系统]     │
│ [↻ 重启相机]            │                  │ [⏻ 安全关机(长按)]│
│                        │ [⊹ 刻度线两点标定]│                  │
│ ── 延迟自测 ──          │                  │ 存储路径 /home/pi │
│ [▶ 开始]  当前 128ms    │ 帧率 14.7 fps    │ 版本 v1.0        │
│  屏幕显示大计时器，用车  │ 码率 1.8 Mbps    │ 时间 14:31 [校时]│
│  上相机拍屏读差值        │ 丢帧 0.4%        │ 日志 [查看]      │
└───────────────────────────────────────────────────────────────┘
```

要点：

- **链路模式 A/B 一键切**：切 nmcli profile，10 秒内完成。现场 2.4G 被干爆时的保命开关。
- **扫描并推荐空闲信道**：跑 `nmcli dev wifi list`，按每个信道的 AP 数和信号强度排序，直接推荐最空的那个，点一下就换。
- **相机参数直通**：滑块 onchange 直接打 `http://CAM/control?var=...&val=...`，实时看画面变化，不用重刷固件。
- **刻度线两点标定**：进入后画面上出现两个可拖圆点，分别拖到摆杆 -10cm 和 +10cm 刻度处，保存 → 全局刻度叠加生效（实时页和回放页共用）。
- **延迟自测**：屏幕上显示 3 位毫秒大数字计时器，把车上相机对准屏幕，看画面里的数字和当前数字差多少 = 端到端延迟。**这个读数直接写进设计报告**（T1-2）。
- **安全关机长按 1.5s**：现场绝不能直接拔电（会烧卡、录像损坏）。关机按钮做得明显，让队友养成习惯。

## 5. 状态机与异常提示（照这个写就不会出现"卡在奇怪状态"）

```
        ┌─── BOOT ───┐  开机，后端起来但还没找到相机
        │            ▼
        │      SEARCHING ──找到相机──▶ LIVE ──选测试项+点REC──▶ RECORDING
        │      （红灯闪，          ◀──相机断──┘        │  │
        │       "搜索相机…"）                        │  └──点停止──▶ SAVING ──▶ LIVE
        │                                            │                    （绿条+立即回放）
        └────────────────────── 相机断线 ────────────┘
                                    │
                             RECORDING 中断线：
                             不停止录制，进 RECONNECT
                             （画面遮罩"重连中"，红色REC计时继续走）
                             恢复后自动开 part2 续录
```

现场异常与 UI 表现（**每种异常都必须有明确的屏幕文字 + 一个可点的自救按钮**，因为我不在场）：

| 异常 | 屏幕表现 | 一键自救 |
|---|---|---|
| 相机没上电/掉线 | 画面遮罩 + "相机离线，重连中 3s"，红灯闪 | [重启相机]（如果供电还在）/ 提示查电池 |
| WiFi AP 没起来 | 顶栏"AP 未启动"黄条 | [重启 AP] |
| 画面卡顿 fps<8 | 黄灯 + "网络拥塞，建议换信道" | [扫描并换台] / [降到 VGA] |
| 磁盘 <2GB | 顶栏红条"存储不足" | [清理 7 天前] |
| ffmpeg 意外退出 | "录制异常已自动重启，已生成分片 2" | 无需操作，继续录 |
| 后端挂了 | 全屏"服务无响应" | [重启服务] |
| 触摸失灵 | — | 网线连笔记本，浏览器开 `http://192.168.50.1:8000`，同一套 UI 可鼠标操作 |
