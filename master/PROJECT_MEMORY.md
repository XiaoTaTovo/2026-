# 2026 H 主控项目记忆

最后更新：2026-07-29

## 冻结范围

- 目标 MCU：MSPM0G3507，LQFP-64。
- CCS：21.0.0；TI Arm Clang：5.1.1 LTS；MSPM0 SDK：2.09.00.01；
  SysConfig：1.28.0。
- 当前唯一开放的可烧录模式：正式要求 2（B2）。
- 电机唯一执行器：一片 TB6612 驱动左右轮，MCU 直接输出 PWM、方向和 STBY。
- 编码器闭环在 MCU 内完成；执行器接口只有 TB6612 PWM、方向、STBY 和本地计数。
- `vision/` 独立开发，本次不改。

## 已建立的软件链

```text
B2 路线 -> 曲率前馈 + 红外巡线修正 -> 左右轮 mm/s
        -> TB6612 目标 RPM -> 编码器 PI -> PWM 百分比
        -> 方向脚 + PWM + STBY -> 左右电机
```

- `drivers/drive_port.h` 是应用层与执行器之间的唯一接口。
- `tb6612.c` 负责方向、PWM、速度 PI 和双轮编码器运动看门狗。
- `firmware.c` 以 5/10/20 ms 周期调度 IMU、红外阵列和整车控制。
- `core/route_executor.c` 只保留连续轨迹、提示和停车三种段。
- `app/h2026_task.c` 只实现 B2；B3-B6 在编译期和路线构建期双重拒绝。
- `vofa_telemetry.c` 使用 PB2/PB3 输出 48 个固定数字字段；调参写入仅在停车时
  允许，且只保存在 RAM。

## 当前参数来源

- 轮径 `65 mm`、轮距 `115 mm`、编码器 `724 count/rev`：现有实车记录，仍应
  在本次装配后复测。
- 弧线等效轮距 `160 mm`：经验值，必须用 R500 实车轨迹复核。
- 速度环 `50 ms`、`Kp=250 milli`、`Ki=600 milli`、输出上限 `60%`：可构建
  初值，不是本次车体的已验收参数。
- 运动看门狗 `10 rpm / 600 ms`：临时安全阈值，需架空轮分别断开左右编码器验证。
- 红外丢线搜索 `80 mm`、终点传感器偏置 `150 mm`：后者必须按机械安装实测。

## 下一项唯一硬件实验

架空左右轮并限制电机电源，先验证正速度命令下两轮方向、两路编码器符号和
