# 2024 H 题固件核心

本目录是 2024 H 题固件核心与外设驱动，不直接包含 SysConfig 生成文件或 TI DriverLib 引脚宏。最终 MSPM0 工程通过 `CarFirmwareConfig` 回调绑定 UART、SPI、ADC 和 GPIO。

## 当前包含

- 16 位累计编码器回绕安全的差速里程计。
- 8 路灰度加权线位置与置信度估计。
- 编码器、IMU、灰度超时与急停监督。
- 直线、单轮前向枢轴转向、半圆弧、提示和停车路径段执行器。
- 第（1）至（4）项路线生成器。
- `CarApp` 统一输入/输出快照接口。
- 串口闭环电机板 Modbus 发送、`0A 03 08/10` 两种反馈帧解析。
- 已验证电机板的四路原子速度帧、PID 配置和非阻塞上电准备时序。
- ICM42688 SPI、灰度 ADC 扫描、按键去抖和非阻塞蜂鸣器驱动。
- 5/10/20/100 ms 周期调度与统一 `CarFirmware_Tick()` 入口。

## 平台适配契约

MSPM0 DriverLib 适配层每个调度周期需要：

1. 把驱动板最新左右累计编码器、IMU yaw、灰度值和按键状态填入 `CarInputSnapshot`。
2. 调用 `CarApp_Update()`。
3. 把 `CarOutputSnapshot.motor` 转换为驱动板左右轮速度命令。
4. 执行 `cue` 对应的非阻塞声光序列。
5. 任一 `faults != 0` 时立即发送四路零速，并在闭环状态下周期刷新零目标。

UART、ADC、SPI 和 GPIO 驱动必须使用最终 SysConfig 生成宏实现，不能在核心层写死。

## 已验证电机板逻辑

- 上电准备顺序为：四路零速 -> A/B/C/D 编码器极性均设为 `1` -> 四路 PID 设为 `40.0/4.9/0` -> 进入闭环 -> 四路零速。
- 相邻配置帧至少间隔 `50 ms`，由 `CarFirmware_Tick()` 非阻塞推进；驱动板或主控重新上电后都会重新配置一次。
- 逻辑左右轮同为正速度时，驱动帧为 `A=0, B=+left, C=0, D=-right`；方向补偿只存在于驱动边界。
- 运行和停车都使用一帧 `0x10` 同时写四路速度。停车帧固定为 `0A 10 00 00 00 04 08 00 00 00 00 00 00 00 00 FD 7D`。
- 暂停、路线结束和故障均保持闭环，并在每个 `20 ms` 控制周期发送四路零速；不再把协议未保证的 `0x0008=0` 当作停车手段。
- 驱动板无写命令 ACK，`motor_armed` 只表示主控已成功发送完整配置序列，最终仍需通过速度反馈和悬空实车测试验收。
- 当前临时换算让默认直行速度约下发 `20` 个驱动板单位，与队友验证工况一致；实测速度单位后必须更新 `H2024_MOTOR_UNITS_PER_MM_S`。

## 尚未冻结

- 默认轮径、轮距、每轮编码器计数都是占位值，必须用实物覆盖。
- 第（3）/（4）项首版采用单轮停止、另一轮前进的枢轴转向；需要实测占用空间，再决定是否升级为双轮前进过渡弧。
- `arc_line_kp` 默认是 0，灰度闭环接入后才做单变量调节。
- 电机速度 `mm/s` 到驱动板命令单位的换算属于平台适配层，当前未知。
