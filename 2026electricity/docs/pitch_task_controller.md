# 摆杆任务控制器

## 已确认的赛题定义

- 任务 2：本模块按中心保持处理，小车循迹与停车由小车主控负责。
- 任务 3：从中心 O 到 `+5 cm`，再到 `-5 cm` 并保持。
- 任务 4：保持中心 O，小车阶段由外部主控负责。
- 任务 5：保持中心 O，小车阶段由外部主控负责。
- 任务 6：`KEY3` 锁定当前有效视觉坐标，`KEY1` 启动后保持该坐标。

相机坐标实测为右侧正、左侧负。当前中心标定为 `-50`，单位均为
`0.1 mm`，因此任务 3 的两个目标依次为 `450` 和 `-550`。

## 按键

- `KEY1`：启动当前任务。自检通过不会自动启动。
- `KEY2`：按 `2 -> 3 -> 4 -> 5 -> 6 -> 2` 切换。切换前先撤销自动控制。
- `KEY3`：仅在任务 6 中锁定最近一帧有效视觉坐标。
- `KEY4`：底层急停并锁存故障，任务控制器不能覆盖。

1000 轮通信自检通过后状态为 `DISABLED_READY`。任务模式只接受实体键：
`KEY1` 会先请求电机使能，收到使能 ACK 后自动 ARM；蓝牙 `A/D` 会被拒绝，
避免绕过任务状态机。任务运行时使用 `KEY4` 急停并锁存。

任务 3 的固定流程是：按 `KEY2` 选到任务 3，再按 `KEY1` 启动。
`KEY3` 与任务 3 无关，只用于任务 6 捕获当前视觉坐标。

## 蓝牙

`PID ON` 后，`PID_SAMPLE` 增加以下字段：

- `task`：当前任务编号。
- `tstate`：任务状态。
- `ttarget`：任务目标坐标，单位 `0.1 mm`。
- `tcapture`：任务 6 捕获坐标。
- `tcapok`：任务 6 捕获是否有效。

任务状态变化时会主动输出 `PITCH_TASK`。`PID?` 可读取任务参数。

可在未 ARM 时修改：

```text
SET CENTER=-50
SET T3OFFSET=500
SET T3TOL=100
SET T3VMAX=100
SET T3DWELL=100
```

上述参数分别是中心坐标、任务 3 偏移量、到达容差和换向前连续进入
目标窗口的时间。前三项单位为 `0.1 mm`，最后一项单位为 `ms`。

## 当前控制修复

位置误差和球速同时进入死区时，控制器不再清除积分状态。此时 P/D
追赶量被抑制，但已学习的 I 保持偏置继续作为丝杆倾角目标，避免球到达
目标附近后因管道静态不水平再次漂走。

实测 `IBAND=150` 时球可能在约 `27.8 mm` 误差处因静摩擦停止，当前默认
改为 `IBAND=350`；`TILTSCALE=180` 曾产生大幅往返，默认仍为 `120`。

## 待实物验证

- 任务 3 在 5 秒限制内完成两段运动。
- `T3TOL=100`、`T3VMAX=100` 和 `T3DWELL=100` 是否会过早换向。
- `T3VMAX` 单位为 `0.1 mm/s`。任务 3 只有在位置进入目标窗口、
  球速不高于该值，并持续满足 `T3DWELL` 后才换向。
- 任务 4/5 在小车加减速和转弯时需要的前馈接口。
- 任务 6 当前是坐标快照，不会保存图像文件；如需实际拍照，要扩展
  STM32 到 MaixCAM 的命令协议。
