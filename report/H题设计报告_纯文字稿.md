# 车载平衡滚球运动控制系统设计报告

> 正文工作稿，不含封面。后续排版为A4时，每页顶部预留3 cm空白，页码置于页脚居中；正文中不得出现学校、队员、指导教师和参赛队编号等身份信息。

## 摘要

本系统面向车载平衡滚球运动控制任务，采用“底盘循线、摆杆调姿、视觉测球、图传记录”分层方案。底盘以MSPM0G3507为控制核心，利用八路红外、编码器和TB6612构成差速巡线与双轮速度闭环；摆杆侧以STM32F407VET6为核心，预留角度传感器、X42S闭环步进电机和MaixCAM球位串口接口；视觉侧以MaixCAM Pro运行YOLO11和水管几何定位，将钢球沿摆杆的一维坐标封装为带CRC的20字节观测帧。系统在软件上设置传感器有效性、观测年龄、通信校验、急停和故障锁存等门限。当前已完成底盘速度环架空轮调试、低速巡线基线、视觉YOLO与水管定位真机显示，以及F407通信与干运行控制框架；静止球往返和行驶中平衡仍需整机标定与重复实测验证。

关键词：循线小车；平衡滚球；机器视觉；闭环控制；串口通信

## 1 方案论证与总体结构

题目要求小车沿黑色环形线运行，并在运行中使直径约10 mm的钢球稳定在长度25 cm的凹槽摆杆指定位置。环形路线由两段1.5 m直线和两段半径500 mm的半圆构成；小车还需具有启动按键和显示装置。由于小车循线、钢球位置测量和摆杆执行器在时间尺度、失效模式和接口上差异显著，系统采用三个相互隔离的控制器，避免把视觉图传、底盘电机和摆杆电机混入同一软件链。

系统总体链路如下：

```text
八路红外、编码器、IMU
          -> MSPM0G3507 -> TB6612 -> 左右轮电机

MaixCAM Pro -> 钢球位置观测帧 -> STM32F407 -> X42S摆杆执行器
                 |                         |
                 +---- 图像显示/录像链 -----+
```

MSPM0底盘控制器只负责车辆行驶：红外阵列估计黑线位置，路线执行器给出左右轮目标速度，编码器闭环保证轮速可控。STM32F407摆杆控制器只负责摆杆方向：解析视觉帧、检查有效性和年龄、生成受限的摆杆动作候选。MaixCAM Pro负责钢球检测和坐标测量；ESP32-CAM与树莓派图传软件作为独立的视频显示与录像链，不进入实时电机闭环。

该分层的优点是：底盘或视频链的故障不会被误解释为摆杆位置；每条链均可单独测量和验收；在视觉失效时，F407能够拒绝旧坐标而不是继续按上一次结果驱动摆杆。

## 2 小车循线与底盘控制

### 2.1 路线与差速运动学

底盘采用双轮差速结构。对中心速度为 \(v\)、等效轮距为 \(b_e\)、路径曲率为 \(\kappa\) 的轨迹，左右轮基础目标速度为：

```text
v_L = v * (1 - kappa * b_e / 2)
v_R = v * (1 + kappa * b_e / 2)
```

直线路段取 \(\kappa=0\)。右转半径500 mm的弧线取 \(\kappa=-1/500\) mm^-1。以当前试验参数 \(v=300\) mm/s、\(b_e=160\) mm计算，左右轮基础速度约为348 mm/s和252 mm/s。曲率前馈先决定转弯趋势，红外控制器仅在此基础上作小量修正，避免巡线环覆盖几何轨迹。

### 2.2 红外巡线控制

八路红外的归一化输出按从左到右赋予位置权重，得到黑线横向位置 `track_position`。控制器将横向误差转换为左右轮差速修正：

```text
u_line = Kp * e + Ki * integral(e) + Kd * derivative_filtered(e)
v_L = v_L + u_line
v_R = v_R - u_line
```

导数项采用一阶低通滤波，首次锁线或重新捕获黑线时清除积分与导数历史，避免导数突跳。直线与弧线使用不同修正限幅：直线允许较大修正以快速回线，弧线限制修正以保留弧线几何前馈。看不到窄线时，系统降低中心速度；超过搜索距离后锁存丢线故障并停止电机。

终点识别不把普通窄线当作A点标志，而要求连续相邻有效通道、足够置信度、足够宽的黑线覆盖和连续确认帧数。确认后，车辆按测得的红外阵列到测试位置的纵向偏置继续行驶，以使规定的车体测试点而非前置传感器停到A点。

### 2.3 双轮速度闭环与安全措施

车轮目标线速度按轮径换算为目标转速：

```text
target_rpm = speed_mm_s * 60 / (pi * wheel_diameter_mm)
```

以轮径65 mm、目标350 mm/s为例，目标约为103 rpm。每50 ms根据编码器增量计算实测转速：

```text
measured_rpm = delta_count * 60000 / (counts_per_rev * elapsed_ms)
```

电机输出由静摩擦/转速前馈和PI调节组成，并带PWM限幅、速度死区、抗积分饱和、零目标清积分和换向清积分。实际执行顺序为先清PWM并关闭TB6612待机，再切换方向，随后开启待机并输出PWM，防止换向瞬间产生不确定驱动。

安全方面，任一轮在目标转速达到门限后，若连续600 ms未收到与目标方向一致的编码器计数，则立即关闭整个TB6612；零目标时PWM、方向和待机脚均清零。主循环外另启用4 s窗口看门狗，只有主循环完整执行后才喂狗。按键启动后的再次按下定义为锁存急停。

## 3 摆杆、视觉与通信设计

### 3.1 钢球位置视觉测量

摆杆使用长度250 mm的凹槽水管，定义水管左端为A端、右端为B端，A端坐标为-125 mm，B端坐标为+125 mm，中点O为0 mm。MaixCAM Pro先运行YOLO11检测钢球候选框；再在HSV空间中提取高亮、低饱和度白色区域，以面积、长宽比和填充率筛选水管轮廓。对水管长轴两端作投影，只有落在水管宽度容差范围内的钢球候选才被接受。

若球心沿A到B的归一化投影为 \(r\)，则球位置为：

```text
x_mm = (r - 0.5) * 250
```

这种“YOLO找球、水管几何约束筛选”的组合，能排除水管外的同类误检。用户通过触摸界面可调整曝光、HSV阈值和YOLO置信度；水管几何确定后可锁定A/B端点，减少轮廓轻微抖动对坐标的影响。锁定期间停止重复运行水管CV，YOLO和串口帧仍按每帧更新，显示刷新降为每两帧一次以降低显示开销。

### 3.2 视觉观测帧与失效语义

MaixCAM每个视觉周期输出固定20字节观测帧，包含帧头、版本、序号、发送时刻、有效位、失败原因、位置、置信度、采图年龄和CRC16-Modbus。位置单位为0.1 mm；无效帧位置固定为-32768，而不是0 mm。因为0 mm正好是控制目标位置，无效帧若被误写为0会伪装为“球在中心”，而-32768能够使下游错误尽早暴露。

F407逐字节解析帧并校验CRC、版本、类型、长度及字段语义。控制器还对观测置信度和总年龄进行二次门控：总年龄为相机给出的采图年龄与F407接收后的等待时间之和，超过150 ms即拒绝；无效、低置信度和过期帧都会清除PID历史，不能沿用旧球位。

【图6建议：绘制20字节串口帧字段表和时序图，标出MaixCAM采图、推理、UART发送、F407接收和控制周期。】

### 3.3 摆杆执行与控制状态

F407通过USART3与X42S闭环步进电机通信，并通过USART6接收MaixCAM数据。软件启动后先执行1000轮“读取状态—读取位置”只读自检；自检失败或通信异常时，手动按键和运动命令均受门禁限制。四按键手动状态机支持使能、正向32脉冲、反向32脉冲和最高优先级停止锁存，用于在机械脱载、限流供电条件下确认方向与重复性。

当前视觉控制模块在50 ms周期内按球位误差计算受限的PID输出，具有+-0.5 mm死区、最大0.20 mm单次候选和960 pulse/mm粗略换算参数。此版本为干运行：它记录运动方向和脉冲候选，但不把视觉候选发送给X42S。因此该模块已证明控制数据流和安全门控的实现方向，尚不能作为自动平衡性能的实测结论。

摆杆角度反馈预留AS5600。自检模块先探测I2C地址0x36和磁场状态，再以20 ms周期采样；磁铁缺失、磁场过强/过弱、NACK或超时均进入失败状态，不会自动置零或使能电机。

## 4 软件流程和故障处理

MSPM0主循环按固定节拍调度：IMU采样5 ms、红外采样10 ms、整车控制20 ms、速度内环50 ms、停车刷新100 ms。VOFA遥测以FireWater文本CSV输出，包括轨迹段、线位置、左右目标/实测转速、PWM、故障位和八路红外归一化值；调参命令仅在停车状态接受。

F407采用“BSP硬件适配—模块协议—应用状态机”三层。UART DMA接收使用硬件循环缓冲和软件环形队列，DMA半传输、全传输和空闲事件均按写入位置差量搬运字节；中断只搬运数据，不解析业务协议。发送端使用DMA队列，避免在上一帧未完成时重复启动DMA。

系统的主要失效动作如下：

| 故障源 | 判定 | 动作 |
| --- | --- | --- |
| 编码器断线/反向 | 600 ms内无同向计数 | 关闭TB6612并锁存故障 |
| 红外丢线 | 超过允许搜索距离 | 停车并记录丢线故障 |
| MCU主循环阻塞 | 看门狗未按时刷新 | 硬件复位 |
| MaixCAM帧CRC/格式错误 | 帧解析失败 | 丢弃该帧并计数 |
| 球位无效、低置信度或超时 | 有效位、置信度、年龄门限不通过 | 清PID历史，不生成运动候选 |
| X42S通信超时或应答拒绝 | 驱动状态机判定失败 | 请求停止并闭锁 |

## 5 测试方法与当前结果

### 5.1 主机测试和构建

截至2026年7月31日，MSPM0工程严格C11主机测试已通过B2路线、安全时间戳、编码器运动看门狗、ICM42688传输失败、TB6612闭环及零速度停车、VOFA帧边界和STOP命令等测试。F407工程的Debug CMake构建已通过。以上结果说明对应源码可构建、关键边界逻辑可在主机测试中执行，不等同于实物完成比赛任务。

MaixCAM协议单元测试已通过有效帧往返、无效位置哨兵和CRC拒绝。水管几何单元测试由于当前主机Python环境未安装OpenCV而未执行；该环境缺失不代表算法失败，需在安装OpenCV的主机或MaixCAM运行环境补跑。

### 5.2 底盘速度环架空轮试验

在350 mm/s、5 s双轮阶跃、25 ms遥测条件下，完成6次从ARM事件到DONE事件的完整试跑。通过逐轮单变量调整，速度PI由初始Kp=250 milli、Ki=600 milli调整为Kp=180 milli、Ki=200 milli，Kd=0、PWM上限60%保持不变。最终确认轮的关键数据如下：

| 项目 | 左轮 | 右轮 |
| --- | ---: | ---: |
| 目标转速 | 约103 rpm | 约103 rpm |
| 峰值转速 | 115 rpm | 115 rpm |
| 最大超调 | 约11.7% | 约11.7% |
| 5%收敛时间 | 约400 ms | 约400 ms |
| 末段平均转速 | 104.10 rpm | 104.65 rpm |
| 故障位/遥测丢弃 | 0/0 | 0/0 |

该结果表明当前架空轮工作点未出现持续振荡、PWM饱和或串口丢帧。由于试验未加载地面摩擦、转弯和摆杆质量，不能直接推导为赛道运行性能。

### 5.3 巡线与传感器基线

低速巡线试验记录显示：在当前等速240 mm/s基线下，完成一圈路线的用时约24.06 s，故障位为0，遥测丢弃为0；最近一次将巡线Kp由0.025提高到0.030后，线位置RMS由约512.9降至440.4，峰值由1822降至1500，未出现无效红外帧或修正限幅。该数据仅说明低速条件下的控制趋势改善，不满足任务2“总时间不超过20 s”的验收要求。

数字红外硬件诊断已验证MCU侧PB17/PB18/PB19为稳定输入、寄存器配置和采样数据一致、50 ms日志无故障；但D5、D6、D7在标注的白/黑纸条件下均保持高电平。因此尚不能宣称八路数字红外模块可用于正式巡线，后续必须完成供电、发射端、安装高度、IR引脚定义和全八路通道的物理排查。

### 5.4 视觉与摆杆链路基线

MaixCAM真机已确认YOLO钢球红框与HSV水管蓝框能够正常显示，模型输入尺寸为320 x 224。当前尚未取得左端、中点、右端三位置的重复定位误差、漏检率、误检率、帧率分位值、采图年龄和连续UART CRC统计，因此不能宣称钢球位置达到+-1 cm精度，也不能证明画面覆盖与录像回放满足任务1。

F407已实现视觉帧解析和干运行控制候选，且设计上禁止视觉候选直接驱动电机。静止球任务和行驶中平衡任务仍需依次完成：相机坐标标定、视觉端到端延迟测试、AS5600角度采样与零点标定、X42S低能量方向试验、脉冲/毫米多组正反向尺量标定、静止球往返试验、最后才是上车联调。

## 6 结论与后续工作

本设计已经形成可独立验证的底盘、摆杆和视觉三层框架。底盘侧已完成速度环架空试验和低速巡线闭环基线；视觉侧已完成YOLO与水管ROI的真机显示，且具有统一的坐标、有效位、原因码和CRC通信契约；摆杆侧已具备X42S协议、通信自检、手动低能量状态机、视觉干运行候选和AS5600自检框架。

现阶段的主要限制是：正式B2底盘尚未完成不超过20 s和停车偏差不超过2 cm的整车验收；摆杆角度闭环及球位置自动闭环尚未上机验证；任务3至任务6均没有可提交的重复测试数据。后续应按“先传感器和机械标定、再单链路低能量验收、最后多链路联调”的顺序推进，并将每次测试的原始日志、参数、条件、失败记录和统计结果一并保留。
